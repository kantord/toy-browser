# toy-browser-engine

The DOM and, behind the default `quickjs` feature, a JavaScript environment around it: load a page, evaluate code against it, read its HTML back, click, focus and type. Build with `--no-default-features` for a document with no interpreter: it is parsed, laid out and acted on, but its scripts are not run.

Part of [toy-browser](https://github.com/kantord/toy-browser), dual-licensed MIT or Apache-2.0.
